# Трекер самолётов 
## Описание проекта 
Программа, которая собирает данные о самолетах в воздушных пространствах тех стран, которые вы выберете.

- Чтобы получить географические координаты стран, будем использовать API nominatim.openstreetmap.org
- получить информацию о самолетах — API opensky-network.org.
 

### Реализованный функционал: 
1. Создан абстрактный класс для работы с API сервисов nominatim.openstreetmap.org и opensky-network.org. 

2. Реализован класс для работы с информацией о самолётах: страна регистрации, позывной, скорость полёта, высота полёта, на земле или в небе. 

3. Созданы классы для работы с файлами JSON для сохранения и извлечения данных. 

4. Разработан функционал для взаимодействия с пользователем через консоль, которая позволит:

* вводить название страны для запроса информации о самолётах; 

* получать топ N самолётов по высоте полёта; 

* фильтровать самолёты по стране их регистрации.

* Узнать количество самолетов находящихся в небе

5. Объединить все компоненты в единую программу и покрыть функционал тестами.

#### Стек технологий
Язык: Python 3.14.

Библиотеки: requests, json, os.

Тестирование: pytest.

Управление зависимостями: Poetry.

IDE: PyCharm.

### Как запустить
1. Установите зависимости:
bash
poetry install  
2. Запустите проект:
bash
poetry run python main.py
Следуйте инструкциям в консоли: введите название страны (например, Canada) и выберите действие.
